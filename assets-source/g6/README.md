# G6 environment-density source card

All G6 runtime artwork is original project-authored Babylon.js geometry assembled
from the existing box, cylinder and low-poly crown templates plus the existing G5
architecture atlas. No external models, textures, reference pixels, downloads,
purchases or image-generation outputs were added.

The vegetation clusters, street furniture, SRAP shelving/product blocks and
façade variants are deterministic code in `src/art.ts` and
`src/architecture.ts`. Existing G3/G5 public assets and their prior provenance
remain unchanged.
